## 二、文件放哪、怎么写

- 每个素材一个文件：`app/src/main/assets/design/stickers/<类别id>-<名字>.svg`，比如 `arrow-curve-loop.svg`、`tape-washi-stripe.svg`。名字用英文小写加连字符。
- 目录：`app/src/main/assets/design/stickers.json`，**由检查脚本生成，不要手写**（见第四节）。

### SVG 规则
1. 根元素写 `viewBox`，**不写** `width`、`height`（App 按需要的大小缩放）。图形尽量贴满 viewBox，四周别留大空白。
2. 不许有 `<script>`、`<image>`、`<foreignObject>`、外部链接、`@import`、事件属性（`onload` 之类）。
3. **不许有 `<text>`**（手机上字体对不上，会变形）。需要字形的（比如「福」字），用 `<path>` 画出来。
4. 单个文件不超过 12KB。路径数字保留 1 位小数就够了。
5. 可以用 `<defs>` 里的渐变、图案（pattern）、滤镜（比如 `feTurbulence` 做纸纹、做撕边），但每个 id 要带上文件名前缀，免得几张贴纸放进同一个页面时 id 撞车：`id="tape-washi-stripe-p1"`。

### 配色（最重要）
贴纸要能跟着整张图换配色。颜色只能写这几种：
- `fill="var(--primary, #E8483B)"` 这种格式：变量 + 默认色。变量只用六个：`--bg`、`--fg`、`--primary`、`--secondary`、`--accent`、`--muted`。默认色用一套好看的暖色就行，整个库统一用同一套默认色。
- `currentColor`：线条类（箭头、圈画、分割线、涂鸦、线描植物）**一律用 `stroke="currentColor"`**，编辑器设文字颜色就能改它的颜色。
- 黑白半透明，比如 `rgba(0,0,0,.15)` 做阴影、`rgba(255,255,255,.6)` 做高光。
- 不要写别的颜色。一个贴纸里最多用三个颜色变量。

### 每个文件开头写元数据
在 `<svg>` 的第一个子元素位置放：

```xml
<metadata>{"name":"绕圈箭头","tags":["箭头","手绘","指向","强调"],"style":"hand","recolor":"stroke","ratio":"wide"}</metadata>
```

- `name`：中文名，6 个字以内。
- `tags`：3～6 个中文关键词，Kavi 会按这些搜。
- `style`：`hand`（手绘派）或 `clean`（干净派）。
- `recolor`：`stroke`（用 currentColor 的线条类）或 `fill`（用颜色变量的）。
- `ratio`：`square`、`wide`（横长）、`tall`（竖长），检查脚本会核对它和 viewBox 对不对得上。
- 标签、印章、气泡、边框再加 `"textArea":[x,y,w,h]`：可以放字的区域（viewBox 坐标），编辑器会把文字放在这块里。
- 纹理加 `"tile":true`：可以平铺。

## 三、审美要求（不合格的不收）

- **像设计师做的素材，不像剪贴画。** 参考手帐贴纸、杂志排版里的装饰元素的质感。线条粗细统一在一个档里（手绘的可以有变化，但一个贴纸内要协调）。
- 手绘派要真像手画的：线条有起笔收笔、轻微不匀，不要用完美的贝塞尔曲线再加个 `stroke-dasharray` 冒充。
- 不要渐变发光、不要 3D 立体效果、不要阴影套阴影、不要卡通大眼睛表情。
- 换上另外两套配色也要好看：用 `styles.json` 里几个风格的配色各试一下。
- 放在 1080 宽的画布上，常见大小是 120～400px 宽，这个大小下要清楚，细节不要碎到看不见。
- **原创**：不许照搬 Canva、稿定、Freepik、Flaticon 或任何品牌的素材、商标、插画。

## 四、检查脚本（你来写）

写 `tools/check_design_stickers.js`（Node，可以参考 `tools/check_design_templates.js` 的写法和依赖）：

1. 逐个检查第二节的规则：根元素有 viewBox、没有 width 和 height、没有禁用的元素和属性、没有 `<text>`、大小不超过 12KB、颜色只出现允许的写法、id 都带文件名前缀、元数据字段齐全而且合法、ratio 和 viewBox 对得上。不合格的打印出文件名和原因，最后退出码非 0。
2. 加 `--write-index` 参数时生成 `app/src/main/assets/design/stickers.json`：
   ```json
   {"version":1,"categories":[{"id":"arrow","name":"手绘箭头"}],
    "stickers":[{"id":"arrow-curve-loop","category":"arrow","name":"绕圈箭头","tags":["箭头","手绘"],"style":"hand","recolor":"stroke","ratio":"wide","viewBox":[0,0,400,160]}]}
   ```
   标签、印章这类带上 `textArea`，纹理带上 `tile`。
3. 生成预览：`design-previews/stickers/_all.png`，按类别分组排成网格，每个贴纸下面写 id。用默认配色出一张，再用另外两套配色（从 `styles.json` 里挑）各出一张：`_all-2.png`、`_all-3.png`。线条类用 `--fg` 当 currentColor。
