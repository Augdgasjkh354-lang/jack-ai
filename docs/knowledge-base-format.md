# 知识库格式

Kavi 的资料库里可以装多个「知识库」：一组文档，整个开关、更新、删除。检索时和自己导入的资料一起搜（关键词 + 按意思）。

## 从哪来

- **Kavi 自己建**：跟 Kavi 说「帮我整理一个 XX 的知识库」，它用 `knowledge_base` 工具建好、一份一份写进去，以后也能改、删。
- **自己建**：资料库里点「新建」，再从它的菜单「导入文件」。
- **从 GitHub 装**：资料库 →「从 GitHub 下载」，填「作者/项目名」或网址；聊天里也可以让 Kavi 装。私有仓库要在 设置 → GitHub 填令牌，令牌要有这个仓库的读取权限。

从 GitHub 装的知识库内容跟着仓库走，不能在手机上改；要改就改仓库，或者新建一个自己的。

## 仓库怎么放

一个文件夹算一个知识库，文件夹里放一份 `KB.md`：

```
my-knowledge/
├── ai-drama/
│   ├── KB.md            ← 必须有：名字和简介
│   ├── 分镜写法.md
│   ├── 案例/            ← 子文件夹也算进来
│   │   └── 第一集.txt
│   └── 平台规则.pdf
└── law/
    ├── KB.md
    └── 劳动合同法.md
```

`KB.md` 开头写名字和简介，下面的正文是给人看的说明（不当资料）：

```markdown
---
name: AI 漫剧
description: 分镜、提示词、平台规则，做 AI 漫剧时查
---

这里写这个知识库收了什么、怎么维护。
```

- 收的文件：md、txt、pdf、docx、csv、tsv、html，以及 json、yaml、xml。代码文件、图片不收。
- 每份文本最大 3 MB，PDF 最大 20 MB；一个知识库最多 500 份。扫描版 PDF 读不出字，要先转文字。
- 文件夹里还套着别的 `KB.md` 的，那部分算另一个知识库。
- **没有 `KB.md` 的普通项目**也能装：整个项目算一个知识库，只收文档类文件（md、txt、pdf……），LICENSE、CHANGELOG 不收。

## 更新

- 改了仓库里的文件、推上去就行。App 每天自动查一次（只下变了的文件，删掉的跟着删），也可以在资料库点「检查更新」，或者跟 Kavi 说「更新知识库」。
- 用户在手机上删掉知识库里的单份文档，下次更新会再下回来；不想要就关掉或删掉整个知识库。

## 安全

知识库只当资料读，不运行里面的任何东西。从 GitHub 来的内容算外部内容：Kavi 检索到时会查有没有冲着 AI 下指令的话，有就标出来、不照做。
