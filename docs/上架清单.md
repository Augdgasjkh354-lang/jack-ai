# 上架清单：订阅制商用版

目标：把 Kavi 做成能上架国内安卓商店、按月订阅收费的产品。现在的仓库是给 Jack 自己用的高权限版，很多东西商店不收、法规不许，或者订阅制下用不上。

> 涉及法规和商店政策的条目，是按 2025 年前后的规定整理的，标了「要核实」的动手前去官方渠道确认一遍（网信办、工信部 APP 备案、各商店开发者文档）。

## 一、先办的手续（不办上不了架、收不了钱）

| 事项 | 说明 | 预计花费 |
|---|---|---|
| 注册主体 | 个体工商户起步（免费，线上办）；商户收款、上架、备案都用它 | 0 |
| 对公账户、商户号 | 微信支付、支付宝商户号；个体户可以用经营者个人账户结算 | 0～几百 |
| 软件著作权 | 华为、小米、OPPO、vivo 大多要。自己在中国版权保护中心申请免费，约 1～2 个月 | 0（代办 300～800） |
| 域名 + 服务器 | 订阅制必须有自己的服务器（见第二节）；域名要实名、备案 | 服务器 ~100/月起，域名 ~50/年 |
| ICP 备案 + APP 备案 | 域名备案、APP 备案都在云厂商后台办，免费，约 2～4 周 | 0 |
| **生成式 AI 服务登记/备案** | 面向公众提供 AI 对话、生成，按《生成式人工智能服务管理暂行办法》要办。调用 DeepSeek 这类已备案模型的应用，一般走属地网信办的「登记」，比大模型「备案」简单，但要材料：安全评估报告、语料和关键词拦截说明、用户协议等。**最大的坎，先打电话问属地网信办（要核实）** | 自己办 0；代办几千到上万 |
| 隐私政策、用户协议 | 商店审核必看：收集哪些信息、第三方 SDK 清单、怎么注销账号 | 0（自己写，可参考模板） |

**3000 元的分法建议**：服务器先买一年小规格（~1000），域名（~50），软著自己办；剩下留给生成式 AI 登记可能要的代办或测评费用。DeepSeek 的接口费从订阅收入里出，开头先充 200～300 块。

## 二、要新做的（订阅制必须有）

1. **服务器中转**：App 不再自己存 DeepSeek Key，所有模型请求走你的服务器转发。Key 放服务器上，用户抓包也拿不到。
2. **账号**：手机号 + 短信验证码登录（短信服务按条付费，约 0.04 元/条）。商店要求能在 App 里**注销账号**。
3. **订阅和额度**：
   - 服务器按账号记 token 用量，**额度判断放在服务器**（现在 App 里的 5 小时和每周额度只是本地的，能被绕过）。
   - 套餐比如：免费体验（一点点额度）、月卡、季卡。微信、支付宝支付，服务器收到支付回调后开通。
   - 安卓商店里卖虚拟商品，有的商店要求走它的支付、抽成（华为、小米等，**要核实**各家政策）。
4. **内容安全**：输入和输出都要过一道敏感词和违规内容拦截（登记时也要说明）。可以先用云厂商的内容安全接口（按量付费）。
5. **AI 生成内容标识**：按《人工智能生成合成内容标识办法》（2025 年 9 月起施行），AI 生成的图片要加标识：文件元数据里的隐式标识必须有，部分场景还要加显式标识（**要核实**设计图属于哪种）。设计图出图时在 PNG 元数据里写上即可。
6. **崩溃收集**：换成自己服务器接收（或接国内的崩溃统计 SDK，并写进隐私政策），不再发到 GitHub。
7. **资源托管**：字体、抠图模型、向量模型现在从 jsDelivr、Hugging Face 镜像下，国内不稳定。换到自己的对象存储（OSS/COS）上。
8. **仓库改私有**：商用后代码不该公开。现在的公开仓库可以留一份旧版，新开发在私有仓库里做。

## 三、要砍的

### 商店不收或法规不许（必须砍）
| 功能 | 原因 |
|---|---|
| Kavi 专用代理、双跳、按 App 分流（VPN） | 国内上架不允许翻墙、代理类功能 |
| 自己检查更新、下载 APK 安装 | 商店禁止绕开它更新；还要去掉「安装未知应用」权限 |
| 崩溃发到 GitHub Issues | 隐私审核过不了 |
| 操作其他 App（无障碍、无线调试、虚拟屏） | 无障碍权限审核很严，基本会被拒；手机操作考试、手机流程一起砍 |
| 下载视频、音乐，m3u8 拼接，「用 Kavi 下载」 | 版权风险 |
| 微信消息交给 Kavi（读通知） | 读别的 App 通知，审核和封号风险都大 |
| 手机数据（通知、联系人、位置、使用时长） | 敏感权限，第一版不要 |
| 远程连接（用 ChatGPT 站点中转） | 境外服务 |
| 其他模型服务（OpenAI、Claude、Gemini、OpenRouter……）、备用模型 | 订阅制只用你服务器上的模型；境外模型在国内提供服务不合规 |
| 从 GitHub 装技能、GitHub 插件 | 境外服务，内容不可控 |
| MCP 连接器 | 内容不可控，第一版不要 |

### 订阅制用不上或太重（建议砍，第一版先不要）
| 功能 | 原因 |
|---|---|
| Linux 沙箱、运行 Python、写代码技能、小工具 | 普通用户用不上；Python 让安装包大一大截 |
| Kavi 浏览器（独立入口、多标签、书签） | 太重；联网搜索、读网页保留，放到服务器上做 |
| 邮箱 | 要填邮箱授权码，普通用户不会配；审核也会问 |
| 问这一屏、悬浮球、设成默认数字助理 | 权限敏感 |
| 本地生成模型（Qwen） | 650MB，用处小 |
| 余额查询、按元计价的统计、每月预算、单次花费上限 | 改成订阅额度，用户不关心多少钱一次 |
| 「风险说明」「完全授权」「以后都允许」 | 高权限版的东西；商用版不该有不确认就发出去的操作 |
| 分头做（分身）里的免费模型轮换 | 依赖用户自己的 Key |

## 四、要留的（核心卖点）

- 聊天、记忆（三层记忆、夜间整理）、问题卡片
- **设计图 + 编辑器**（最大卖点）：风格库、模板、成组小红书、裁剪滤镜、抠图（本地模型）
- Word、PPT、Excel、PDF 生成和修改；文件库；文件里直接预览
- 联网搜索、读网页、深度研究（服务器上调搜索接口）
- 内容技能：小红书运营、抖音运营、闲鱼卖货、广告合规、合同挑坑、去 AI 味、小说、生图提示词、视频分镜
- 提醒、定时任务、写进日历、表格记账、拍票据记账
- 转文字、录音纪要、OCR、文件工具箱（图片、PDF、视频压缩）
- 项目、资料库、备份恢复、应用锁、桌面小组件、深浅色

## 五、要改的

- **新手引导**：现在一打开要填 DeepSeek Key。改成：登录 → 送体验额度 → 直接能用。
- **设置页**：大幅精简。去掉所有 Key、模型服务、代理、操作其他 App、手机数据入口；加「我的账号」「我的订阅」「注销账号」「隐私政策」「用户协议」。
- **模型选择**：顶部不再让选模型（或只给「快速 / 深度」两档），背后由服务器决定。
- **提示词里「高权限」的部分**：砍掉的工具相关的说明一起删，免得模型说能做其实做不了。
- **权限清单**：AndroidManifest 里只留用得上的（相机、麦克风、通知、日历、前台服务……），每个都要在隐私政策里写清楚用途。
- **App 名字和图标**：查一下「Kavi」商标有没有被注册（**要核实**），上架名字要和软著一致。

## 六、建议顺序

1. **第 1～2 周**：问清生成式 AI 登记的要求（决定能不能上）；注册个体户；申请软著；买服务器和域名，开始备案。
2. **第 2～4 周**：在私有仓库里拉商用分支，按第三节砍功能（砍完先自己用一周，确认没砍坏）。
3. **第 3～6 周**：做服务器中转、账号、额度、支付、内容安全（第二节）。
4. **第 6～8 周**：隐私政策、用户协议、AI 标识；内测（找 10～20 个人用）。
5. **手续齐了**：提交华为、小米、OPPO、vivo、应用宝。

砍功能和做服务器可以同时进行；手续最慢，最先开始。
