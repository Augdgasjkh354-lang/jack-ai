# 设计编辑器：目标和路线

Kavi 做出来的设计图（小红书图文、海报、邀请函、名片……），用户要能**自己动手改**，而且改得顺手、改完好看。参照对象是 Canva、稿定设计、醒图这一档的手机端编辑器。

这份文档定的是**最终要做到什么样**，以及按什么顺序做。每做完一项，在后面打勾、写上版本。

## 一、几条不变的原则

1. **底稿是唯一的真相。** 编辑器改的是图旁边的底稿 `.html`，保存时重新出图。所以 Kavi 和用户改的是同一份东西：用户拖完位置，再跟 Kavi 说「标题换个说法」，Kavi 接着改，不会把用户的改动冲掉。反过来也一样。
2. **所见即所得。** 编辑器和出图用同一套渲染：同一个 WebView 页面、同一套字体、同一份 `fill.js`。编辑器里看到什么，出来的 PNG 就是什么。
3. **AI 是一等公民。** 编辑器不是 Kavi 之外的另一个工具。选中一块就能直接让 Kavi 改这一块；Kavi 改完，编辑器里立刻看到，还能撤销。
4. **默认好看，很难改丑。** 配色从风格库里换、字体从清单里挑、吸附和对齐线帮着摆。高级用户能自由调，新手乱点也不至于毁掉一张图。
5. **手机优先。** 单手能操作，手势要符合直觉；工具栏按选中的东西变化，不堆一屏按钮。

## 二、现在有什么（初版框架）

位置：`ui/DesignEditor.kt`（界面）、`assets/design/editor.js`（网页里的手势和编辑）。入口是聊天里设计图下方的「编辑」。

- [x] 打开底稿，按画布比例整张放进屏幕；长图铺满宽、上下滑。
- [x] 点一下选中（文字位、图片位、列表项、图标、装饰图形），蓝框标出来。
- [x] 按住选中的东西拖动；两指缩放、旋转；旋转接近水平或竖直时自动吸附。
- [x] 拖到画布横竖中线附近时吸过去，显示粉色对齐线。
- [x] 改字（支持换行）、字号加减、颜色（这张图自己的六个配色加常用色）、字体（字体清单，按需下载）、粗细、对齐。
- [x] 底色、上移一层、下移一层、复位（去掉位移缩放旋转）、隐藏和显示。
- [x] 换图：对话文件夹里的图片，或者从相册选。
- [x] 整张换配色：风格库里的所有配色一键套用。
- [x] 撤销、重做（60 步）。
- [x] 保存：写回底稿并重新出图（有 PDF 的连 PDF 一起），聊天里的图跟着刷新；没保存就退出会问一句。

## 三、最终目标（按模块）

### 1. 选择和变换
- [ ] 四角拖拽缩放手柄、旋转手柄（不只靠两指）。
- [ ] 文字框拖边改宽度（自动换行），不是整体缩放。
- [ ] 多选：长按进入多选，或框选；多选后一起移动、对齐、等距分布。
- [ ] 编组和取消编组。
- [ ] 锁定元素（背景、装饰锁住，不会误点）。
- [ ] 轻点穿透：点一下选最上层，再点同一处选下面那层。
- [ ] 微调：选中后上下左右按钮一次挪 1px、长按连续挪。
- [ ] 数值面板：精确输入位置、大小、角度、透明度。

### 2. 对齐和吸附
- [ ] 吸附到画布边、安全边距线、其他元素的边和中线（智能参考线，像 Figma）。
- [ ] 显示间距数值；和其他元素间距相等时提示。
- [ ] 一键对齐：左、中、右、上、中、下，相对画布或相对多选的其他元素。
- [ ] 网格和安全区开关（小红书裁切区、名片出血线）。

### 3. 文字
- [ ] 在画布上直接编辑（光标、选中一段文字），不用弹框。
- [ ] 一段文字里局部改样式：某几个字换色、加粗、加荧光笔底、加下划线。
- [ ] 行距、字距、段落间距。
- [ ] 文字效果：描边、硬投影、软阴影、渐变字、弯曲文字、竖排。
- [ ] 文字样式预设：标题、副标题、正文、标签，一键套用（跟着风格走）。
- [ ] 自动缩字号：内容变长时在框里自动缩到装得下。
- [ ] 添加新的文字框。

### 4. 图片
- [ ] 裁剪（自由、1:1、3:4、圆形），框里拖动和缩放图片本身（不动框）。
- [ ] 滤镜和调色：亮度、对比度、饱和度、色温，几套预设滤镜（胶片、清新、黑白）。
- [ ] 抠图：一键去背景（手机端模型或云端）。
- [ ] 图片蒙层：渐变压暗，保证压在上面的字看得清。
- [ ] 圆角、描边、阴影、透明度。
- [ ] 把图片拖进画布任意位置（不只替换已有的图片位）。

### 5. 元素库
- [ ] 形状：矩形、圆、线、箭头、星形、对话气泡，填充和描边都走配色变量。
- [ ] 贴纸：胶带、便利贴、手绘箭头和圈、印章、标签、表情，按风格分组，颜色跟着配色变。
- [ ] 图标：现有的 Lucide/Tabler 图标可以搜索添加。
- [ ] 装饰纹理：纸纹、颗粒、网格、点阵，一键加到背景。
- [ ] 图表：在设计图里放一个简单的柱状、环形、大数字图表，可改数据。

### 6. 页面和配色
- [ ] 背景：纯色、渐变（克制的两色）、图片、纹理。
- [ ] 配色面板：改单个变量（主色、辅色……），全图跟着变；从照片里取色生成配色。
- [ ] 品牌套件：存用户的品牌色、字体、Logo，所有设计一键套用。
- [ ] 换尺寸：同一份设计一键改成方图、海报、公众号封面，自动重排（AI 辅助）。
- [ ] 换模板保留内容：内容不动，换一套同类型模板。

### 7. 成组的图（小红书一组 6～9 张）
- [ ] 一个编辑器里翻页编辑整组，底部是缩略图条。
- [ ] 改一张的配色、字体，问要不要同步到整组。
- [ ] 加页、删页、调顺序、复制一页。
- [ ] 一次导出整组，按顺序存进相册。

### 8. 图层
- [ ] 图层面板：列出所有元素，拖动调顺序，显示和隐藏，锁定，重命名。
- [ ] 选中的元素在图层面板里高亮，反过来点图层也能选中画布里的元素。

### 9. 和 Kavi 一起改
- [ ] 选中一块，直接输入「这里写得更抓人」「换成手写体」，Kavi 只改这一块（它改的是底稿里这个元素）。
- [ ] 「帮我看看哪里不好看」：Kavi 用审美技能自评这张图，把建议标在画布上，点一下就能应用。
- [ ] Kavi 改完，编辑器里显示改了哪里，可以一键撤销。
- [ ] 用户在编辑器里的习惯（总把标题调大、总换成某个字体），记成偏好，下次 Kavi 直接这么做。

### 10. 历史和协作
- [ ] 版本历史：每次保存留一版，能看、能恢复。
- [ ] 编辑中途被系统杀掉、来电话，回来草稿还在（自动存草稿）。
- [ ] 分享可编辑的设计给别人（导出底稿包）。

### 11. 导出
- [ ] PNG、JPG（选质量）、PDF（打印，带出血）、透明背景 PNG。
- [ ] 2 倍、3 倍高清导出。
- [ ] 直接分享到小红书、微信，或者存进相册。

### 12. 体验和性能
- [ ] 手势 60 帧不掉帧；大图、长图也流畅。
- [ ] 平板和横屏布局：工具栏放侧边。
- [ ] 新手引导：第一次打开时，三步提示怎么选中、怎么拖、怎么保存。
- [ ] 无障碍：按钮都有说明，读屏能用。

## 四、路线（建议的先后顺序）

按「用户最常做的改动」排：

1. **第 1 步（已完成）**：框架。选中、拖动、缩放旋转、改字、换色、换字体、换图、撤销、保存。
2. **第 2 步：改字顺手。** 在画布上直接编辑、局部改样式、行距字距、描边和投影、自动缩字号、添加文字框。
3. **第 3 步：摆得整齐。** 缩放和旋转手柄、智能参考线和间距、多选和对齐、锁定、微调。
4. **第 4 步：成组编辑。** 翻页编辑整组、同步风格、导出整组。小红书图文的核心场景。
5. **第 5 步：元素库。** 形状、贴纸、图标、纹理。
6. **第 6 步：图片处理。** 裁剪、滤镜、去背景、蒙层。
7. **第 7 步：和 Kavi 一起改。** 选中一块直接让 Kavi 改、Kavi 标注建议。
8. **第 8 步：图层面板、版本历史、品牌套件、换尺寸。**

## 五、技术上的约定

- 编辑器所有改动都落在底稿的 DOM 上：位置、大小、旋转写成元素的 `translate`、`scale`、`rotate`，样式写成元素自己的 `style`。新加的元素也是普通 DOM，带 `data-slot`，这样 `fill.js`、出图检查、Kavi 的 edit_file 都认得。
- 编辑器临时加的东西（选中框、参考线、临时字体样式）一律带 `data-kavi-temp`，保存时 `kaviSource()` 会去掉。
- 颜色尽量写成 `var(--primary)` 这类变量引用，不写死成 `#xxxxxx`，这样整张换配色时跟着变。
- 撤销、重做以「一次完整的操作」为单位（一次拖动、一次改字），不是每一帧。
- 手势归编辑器，页面滚动只在没有拖动选中元素时发生。
