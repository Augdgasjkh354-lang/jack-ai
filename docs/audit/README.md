## 严重程度校正

报告里有几条判重了，以这里为准：

- 百炼免费池探测（provider #1）：每个模型每天发 1 次、只要 1 个 token，一天不到一分钱；README 也要求先开「免费额度用完即停」。**低**。
- Work 单次花费上限（background #5）：最多多花一轮请求（几分钱），上限本来就是软的。**中**。
- 断点先删、Worker 后确认（background #2）：只有几毫秒的窗口。**中**。

## 2026-11-21 Claude 全面检查（另找到的）

- ✅ 外部 App 能把指向 Kavi 私有文件的地址（`file://` 数据目录、Kavi 自己的 content://、「问这一屏」的文件路径）递给 MainActivity，Kavi 会把它当附件放进新对话。现在入口处拦掉（`ShareGuard`），Kavi 自己浏览器带每次启动随机的暗号照收。
- ✅ 项目里的对话共用一个文件夹，重新回答、改消息时把整个文件夹退回，会删掉别的对话后来放进去的文件。项目里不再自动退回。
- ✅ 回答收尾时没用上的插话：用户切到别的对话就丢了。现在照发，发不出去就先记进对话。
- ✅ 语音对话里麦克风打不开也说成「半分钟没听到你说话」。
- ✅ 通知上「有用 / 别为这种事找我」在裸线程里读写，出错会让 App 闪退。
- Android Lint 全量跑过：报的错误是误报（produceState）或故意的（CSV 开头的 BOM），没有会闪退的。
