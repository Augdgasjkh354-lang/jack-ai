## 严重程度校正

报告里有几条判重了，以这里为准：

- 百炼免费池探测（provider #1）：每个模型每天发 1 次、只要 1 个 token，一天不到一分钱；README 也要求先开「免费额度用完即停」。**低**。
- Work 单次花费上限（background #5）：最多多花一轮请求（几分钱），上限本来就是软的。**中**。
- 断点先删、Worker 后确认（background #2）：只有几毫秒的窗口。**中**。
