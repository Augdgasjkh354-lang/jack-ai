## 一、Kavi 是什么

1. Kavi 是一个运行在你手机上的 AI 助手，能对话、搜索、处理文件、做文档和表格、剪视频、管理提醒和日程等。
2. **Kavi 本身不提供 AI 模型。**回答由你选择的第三方模型服务商生成（默认是 DeepSeek），你需要自己在服务商那里申请 API Key 并填进 Kavi。
3. **调用模型、搜索、语音等服务产生的费用，由你和对应的服务商结算，跟我们无关。**Kavi 里显示的花费只是按公开价格估算的，以服务商的账单为准。
4. 我们可能会更新、调整或停止部分功能，重要变化会在 App 内提示。

## 二、关于 AI 生成的内容

1. **AI 生成的内容可能不准确、不完整，也可能过时或带有偏见。**请自己判断后再使用，重要的事要核实。
2. **Kavi 的回答不构成医疗、法律、财务、投资、心理等专业意见。**涉及健康、法律、钱和安全的事，请咨询有资质的专业人士。
3. 按国家有关规定，AI 生成的内容要做标识。你把 AI 生成的文字、图片、音频、视频发布到网上时，应当按平台要求标注「AI 生成」，不得删除或隐藏这类标识。
4. Kavi 替你做的操作，比如发邮件、修改或删除文件、写入日历，执行前会请你确认。**如果你在设置里打开了「完全授权」，这些操作会直接执行，不再询问，由此产生的后果由你自己承担。**

2. 你应当保证对自己输入和上传的内容拥有合法权利，或者已经得到授权，不侵犯他人的著作权、肖像权、隐私等权利。
3. 你用 Kavi 生成的内容如何使用、发布，由你自己负责。

## 四、不得用 Kavi 做的事

你承诺不用 Kavi 做下面这些事：

1. 生成、传播违反法律法规的内容，例如危害国家安全、煽动颠覆、宣扬恐怖主义和极端主义、民族仇恨和歧视、暴力、淫秽色情、赌博、虚假信息等。
2. 侵犯他人合法权益，例如诽谤、骚扰、冒充他人、侵犯知识产权、非法收集或泄露他人个人信息。
3. 实施诈骗、制作恶意软件、攻击网络和系统，或者其他违法犯罪活动。
4. 违反你所用的第三方服务（模型服务商、邮箱、GitHub、Notion 等）的使用条款。
5. 对 Kavi 进行破解、反向工程，或者用它侵害他人权益。法律允许的情况除外。

违反以上约定的，责任由你自己承担。
