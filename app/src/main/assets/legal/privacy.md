## 一、先说最重要的几点

1. **我们没有自己的服务器，你不需要注册账号。**你的对话、记忆、文件、设置都存在你自己的手机上，我们拿不到。
2. **你和 AI 说的话，会直接发给你选择的模型服务商**（默认是 DeepSeek，也可以是你自己添加的其他服务商），用的是你自己填写的 API Key。这些服务商按它们自己的隐私政策处理数据，不经过我们。
3. **联系人、位置这些敏感权限默认关闭**，只有你在设置里主动打开、并在系统弹窗里同意后才会使用。
4. **我们不投放广告，不出售你的信息，不接入第三方统计或广告 SDK。**

## 二、我们怎么收集和使用你的信息

Kavi 的信息处理都发生在你的手机上，或者发生在你手机和你选择的第三方服务之间。下面按功能说明。

### 1. 和 AI 对话（基本功能）

- **处理的信息**：你输入的文字，你发送的图片、文件、语音，以及回答需要的上下文。上下文包括：本对话的历史；你让 Kavi 记住的记忆；和问题相关的文件内容；当前日期和时间。
- **发给谁**：**你在设置里选择的模型服务商**。默认是 DeepSeek（杭州深度求索人工智能基础技术研究有限公司），也可以是你自己添加的其他服务商。
- **为什么**：没有这一步就无法生成回答。

### 2. 联网搜索、读网页（可选）

- 你让 Kavi 搜索时，**搜索词**会发给 DeepSeek 的搜索服务；如果你填了 Tavily 或 Exa 的 Key，也会发给 Tavily 或 Exa。
- Kavi 读网页时，你的手机会直接访问这个网页，网站能看到你的网络地址。

### 3. 语音输入、录音转文字（可选，需要麦克风权限）

- 只有你按下录音或语音按钮时才会录音。
- 录音会发给转文字服务（DeepSeek，或你在设置里配置的服务）。转好的文字和录音文件存在手机本地。

### 4. 朗读和 AI 配音（可选）

- 要朗读或配音的文字会发给 DeepSeek 的语音合成服务。

### 5. 拍照、选图（可选，需要相机权限）

- 只有你点拍照时才会打开相机。照片在需要时随问题发给模型服务商。

### 6. 图片里的文字识别（离线）

- 把照片里的表格转成 Excel 这类功能，用的是谷歌 ML Kit 的离线文字识别，**图片不会上传**。
- ML Kit 可能会向谷歌发送不含图片内容的诊断和使用统计（例如识别是否成功、耗时）。

### 7. 日历和提醒（可选，需要日历、通知、闹钟权限）

- 你让 Kavi 加日程、查日程时，读写手机日历。
- 提醒、定时任务在手机本地按时间触发；**开机后自动恢复**，所以需要「开机自启」。
- 通知权限用来在到点时提醒你、告诉你后台任务做完了。

### 8. 联系人（可选，默认关闭）

- 打开后，你说「给张三发邮件」这类话时，Kavi 会在手机通讯录里按名字查电话或邮箱。
- **查到的那几条**会在需要时发给模型服务商，**不会上传整个通讯录**。

### 9. 位置（可选，默认关闭）

- 打开后，只有你问到「附近」「天气」「路线」这类问题时才定位一次，**不在后台持续跟踪**。
- 定位结果（大致地址或坐标）会发给模型服务商，用来回答你的问题。

### 10. 手机文件夹（可选）

- 你在系统的文件选择器里授权某个文件夹后，Kavi 只能读写这个文件夹。
- 只有在你让它处理时，相关文件的内容才会发给模型服务商。

### 11. 你主动连接的服务（可选）

下面这些服务都由**你自己填写账号或令牌**，你的手机直接和这些服务通信，不经过我们：

- **邮箱**：通过 IMAP 收信、SMTP 发信。发信前会先让你确认。
- **GitHub、Notion**：读写你授权的仓库和页面。
- **MCP 连接器**：只连接你添加的地址。
- **远程连接**：连接你自己部署的站点，让你在别的设备上使用这台手机上的 Kavi。

### 12. 本地模型（可选）

- 你选择下载本地向量模型时，会从魔搭社区（modelscope.cn）或 Hugging Face 下载模型文件。
- 下载完以后，找记忆、查资料都在手机上离线完成。

### 13. 加密 DNS

- 为了防止公共 Wi-Fi 或运营商看到你访问了哪些网站，Kavi 联网时会用阿里云公共 DNS（dns.alidns.com）的加密方式解析域名。
- 阿里云会收到 Kavi 要访问的域名。

## 三、我们不做的事

- 不收集设备标识（IMEI、Android ID、广告 ID 等），不做用户画像，不做个性化广告。
- 不接入第三方统计、广告、推送 SDK。
- 正式版不自动上报崩溃信息。
- 不在后台读取你的剪贴板、通知、屏幕内容或其他 App 的数据。

---

## 四、信息的存储和保护

- **存在哪**：对话、记忆、文件、设置都存在你手机上 Kavi 的私有目录里。
- **怎么保护**：你填写的 API Key、令牌、邮箱授权码，在写入手机前会用安卓系统密钥库里的密钥加密。你还可以在「设置 → 隐私和数据」里打开应用锁。
- **系统备份**：如果你在手机系统里开了云备份（手机厂商或谷歌的备份），系统可能会把 Kavi 的数据一起备份。设置文件和你的密钥不在备份范围内。
- **存多久**：数据一直存在你的手机上，直到你在 App 里删除，或者卸载 Kavi。卸载后，手机上 Kavi 的数据会被系统删除。
- **发给第三方的数据**：由对应的服务商按它们的政策保存和处理，我们无法控制，也无法替你删除。

## 七、你的权利

- **查看和修改**：对话、记忆、文件、设置都可以在 App 里直接查看和修改。
- **删除**：可以删除单个对话、单条记忆，或者在「设置 → 隐私和数据」里清空全部聊天记录、重置记忆；卸载 App 会删除手机上的全部数据。
- **撤回同意**：可以随时关掉对应功能的开关，或者在系统设置里撤回权限。撤回不影响之前已经进行的处理。
- **导出**：可以在设置里导出备份文件。
- **注销**：Kavi 没有账号体系，删除数据并卸载就等于注销。
- 发给第三方服务商的数据，请按它们公布的方式行使权利。
